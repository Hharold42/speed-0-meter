# Участие в разработке

## Окружение

Нужен Node.js 22 или новее.

```bash
npm install
```

## Перед коммитом

```bash
npm run lint          # ESLint
npm run format        # Prettier (проверка: npm run format:check)
npm run typecheck     # проверка типов
npm test              # сборка и все тесты
```

Те же проверки запускает CI (`.github/workflows/ci.yml`).

## Правила

- Ядро замера (`src/core`) не должно зависеть от консоли и HTTP-сервера. Его используют и CLI, и сервер.
- Любое изменение поведения сопровождается тестом. Для сетевых сценариев используйте локальный сервер из `src/testing/target-server.ts`, а не интернет.
- В рантайме нет внешних зависимостей. Новую зависимость добавляйте, только если без неё нельзя.
- Сообщения коммитов и пользовательские тексты пишем на русском.
- Логику страницы держим в `public/app.js`, стили в `public/styles.css`, а не в HTML.
